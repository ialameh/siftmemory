# /siftmemory:team review

View pending team memory reviews.

## Usage

```
/siftmemory:team review
```

## Description

Lists checkpoints and claims pending review before they can be promoted or approved for team use.

## Examples

```
/siftmemory:team review
```

## See Also

- `/siftmemory:team approve` - Approve a checkpoint for team use
- `/siftmemory:team reject` - Reject a checkpoint
- `/siftmemory:team status` - View team memory state
