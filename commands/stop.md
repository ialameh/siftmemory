# /siftmemory:stop

Stops the running SiftMemory daemon. The daemon will auto-restart on next Claude Code session if auto-start is enabled.

## Examples

```
/siftmemory:stop
```

## See Also

- `/siftmemory:start` - Start the daemon
- `/siftmemory:status` - Check status
